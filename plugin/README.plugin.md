# RobloxPlug - Studio Plugin Installation Guide

## Prerequisites

- Roblox Studio installed
- The RobloxPlug server running locally (`npm run dev:server` from the monorepo root)
- HttpService enabled in your game (Game Settings > Security > Allow HTTP Requests)

## Installation

### Method 1: Local Plugin File

1. Copy `Plugin.lua` to your Roblox Studio plugins folder:
   - **Windows**: `%LOCALAPPDATA%\Roblox\Plugins\`
   - **macOS**: `~/Documents/Roblox/Plugins/`
2. Rename it to `RobloxPlug.lua`
3. Restart Roblox Studio — the plugin loads automatically

### Method 2: Script in Studio

1. Open Roblox Studio
2. Go to **View > Command Bar**
3. Create a new Script in `ServerStorage` (temporary) and paste the contents of `Plugin.lua`
4. Save as a local plugin: right-click the script > **Save as Local Plugin**

## Usage

1. **Start the server**: Run `npm run dev` from the project root
2. **Get a session token**: Open `http://localhost:3000` in your browser and click "Connect Studio"
3. **Copy the token** displayed on screen
4. **In Roblox Studio**: Click the "RobloxPlug" button in the toolbar to open the widget
5. **Paste your session token** into the token field
6. **Click Connect** — the status should turn green
7. **Go to the chat** (`http://localhost:3000/chat`) and start describing scripts
8. Scripts will automatically appear in your game hierarchy!

## How It Works

The plugin connects to the RobloxPlug backend server via HTTP polling:

1. On connect, it registers your session token with the server
2. Every 2 seconds, it polls for new scripts generated by the AI
3. When a script is received, it:
   - Creates the appropriate instance (Script, LocalScript, or ModuleScript)
   - Places it at the specified parent path (e.g., ServerScriptService)
   - Sets the source code
   - Selects the new script in the Explorer
   - Logs the action in the plugin widget

## Troubleshooting

- **"HTTP 403" errors**: Enable HTTP requests in Game Settings > Security > Allow HTTP Requests
- **Can't connect**: Make sure the server is running on `http://localhost:3001`
- **Scripts not appearing**: Check the Output window for `[RobloxPlug]` messages
- **Wrong parent path**: The plugin resolves paths like "ServerScriptService" to `game:GetService("ServerScriptService")`. Nested paths use dot notation (e.g., "ReplicatedStorage.Modules")
